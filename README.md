# 🔮 Site de Signos — PHP, HTML e XML

Projeto web desenvolvido como atividade prática do curso de Análise e Desenvolvimento de Sistemas (ADS).

O sistema permite consultar o signo do zodíaco a partir da data de nascimento informada pelo usuário, utilizando PHP para processar os dados e XML para armazenar as informações dos signos.

## 🚀 Tecnologias utilizadas

- **PHP:** processamento das informações e lógica da aplicação.
- **HTML5:** estrutura das páginas.
- **CSS3:** estilização da interface.
- **Bootstrap:** recursos para construção da interface.
- **XML:** armazenamento dos dados dos signos.
- **XAMPP:** ambiente local para execução do PHP.

## ⚙️ Funcionalidades

- Formulário para informar a data de nascimento.
- Processamento da data utilizando PHP.
- Consulta às informações armazenadas no arquivo XML.
- Exibição do signo correspondente à data informada.

## 💻 Como executar o projeto

1. Instale o [XAMPP](https://www.apachefriends.org/pt_br/index.html).
2. Copie a pasta do projeto para o diretório `htdocs` do XAMPP.
3. Inicie o Apache pelo painel de controle do XAMPP.
4. Abra o navegador e acesse:

   `http://localhost/Project/`

5. Informe a data de nascimento no formulário para testar o sistema.
